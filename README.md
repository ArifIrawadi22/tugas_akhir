## 📌 Deskripsi
Aplikasi **Toko Kosmetik** berbasis **Flask Python** yang digunakan untuk manajemen produk, admin, dan transaksi sederhana.

---

## 🚀 Fitur
- 🔐 Login Admin
- 📦 CRUD Produk (Tambah, Edit, Hapus)
- 🖼️ Upload gambar produk
- 🛒 Tampilan katalog produk
- 📊 Database SQLite
- 📱 Responsive UI (Bootstrap)

---

## 🛠️ Teknologi yang digunakan
- Python
- Flask
- SQLite
- HTML, CSS, JavaScript
- Bootstrap 5
